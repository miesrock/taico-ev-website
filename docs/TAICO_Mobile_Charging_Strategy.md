# TAICO 移动充电产品线业务战略规划

## 1. 市场战略与目标区域分析

经过市场调研与案例对标，我们明确了三大核心 validated 市场：

### 1.1 中东（UAE/沙特/迪拜）
*   **驱动力**：极端高温下的续航焦虑 (45°C+)、别墅区/游艇会建桩审批极其复杂。
*   **策略**：对标迪拜案例（80%体验转付费）。
*   **目标**：汽车经销商、高端物业、酒店集团、本地充电运营商。

### 1.2 欧洲农业电气化
*   **驱动力**：葡萄园/大型农场对无电网区域设备补能的刚需、欧盟法规与补贴（ADEME 补贴窗口期）。
*   **策略**：以光储充一体化解决方案 (F200120) 打入智慧农场与大型酒庄。
*   **目标**：大型农业合作社、农业机械集成商、农业光伏安装商。

### 1.3 澳洲 4S 经销商网络
*   **驱动力**：EV 渗透率高但基础设施配套跟不上、DRIVEN 计划政府补贴 (每个充电口高达$3,000返利)。
*   **策略**：以 G2V 便携快充低门槛接入经销商网点。
*   **目标**：大型经销商集团 (AP Eagers)、中国品牌 (BYD/MG) 澳洲经销商、商业地产停车场。

## 2. 客户开发与 Outreach 策略

### 2.1 客户画像（6类核心）
1.  **汽车经销商/4S店**：提升试驾交付体验，增加收入。
2.  **商业地产/物业**：无需电网扩容，提升商业空间溢价。
3.  **工程承包商**：减少充电路程空驶 (时间折叠技术)，提升工期效率。
4.  **能源运营商**：无需漫长审批，快速抢占充电市场。
5.  **车队/物流**：保障关键路线的连续作业。
6.  **政府/应急机构**：移动备用电源，高可靠性。

### 2.2 开发信策略 (组合拳)
*   **核心理念**：不卖产品，卖 ROI 和业务解决方案。
*   **流程**：LinkedIn 个性化好友 -> 互动 -> 邮件发送案例 -> LinkedIn 私信跟进 -> 电话跟进。
*   **要点**：每封信必须包含行业具体数据（如某地 80% 会员转化率、工期缩短 25%）。

## 3. 独立站建设策略

鉴于 XIAOFU 是我们的 OEM 技术提供商，而 TAICO 是面向市场的品牌方，必须建立独立品牌形象。

### 3.1 品牌隔离策略
*   **方案**：建立独立子品牌站（如 `taico-charging.com`）。
*   **原因**：品牌认知清晰（方案商 vs 电池制造商）、利于独立 SEO、视觉调性更匹配终端市场。
*   **处理背书**：在 footer 标注 *"Powered by TAICO — 22+ Years of Manufacturing Excellence"*，将制造背书转化为信任资产。

### 3.2 站点架构建议
*   **首页**：首屏视频展示部署场景，快速传达 "Mobile Energy. Deployed in Minutes."。
*   **CMS 管理**：必须将“案例研究 (Case Studies)”作为核心，而非产品型号。
*   **功能工具**：增加 ROI 计算器，引导客户根据自身需求计算预估回报。

## 4. 技术部署与托管建议

为确保全球客户的访问体验和品牌独立性，建议如下：

### 4.1 托管方案 (推荐方案 1)
*   **平台**：Webflow 或 Framer。
*   **理由**：
    *   自带全球 CDN，无需管理服务器。
    *   非常适合制作 B2B 落地页及复杂的 CMS 案例库。
    *   针对中东、澳洲、欧洲市场的加载速度优于自建机房。

### 4.2 DNS 配置 (强要求)
*   **DNS 管理**：强烈推荐使用 **Cloudflare** 作为 DNS 解析服务。
*   **Cloudflare Proxy**：套上 Cloudflare 的 CDN，不仅能解决当前网站的机器人验证拦截问题，还能根据访问者地理位置自动路由到最近节点，极大降低延迟。

### 4.3 实施顺序
1.  **购买独立域名**：如 `taico-charging.com`。
2.  **选定平台**：根据内部团队技术储备选择 Webflow (适合长期维护/SEO) 或 Framer (适合快速上线/动效演示)。
3.  **配置 Cloudflare**：先行解决网络访问基础的稳定性与安全性。
