## 一、这个项目到底是什么？

**一句话：**  
给 **TAICO EV** 做英文官网（独立站），域名 **taicoev.com**，面向海外 B2B 客户，卖的是「移动充电 / 移动储能」解决方案，不是单纯的型号目录。

**和老站的关系：**

| | 老站 taicopower.com | 新站 taicoev.com |
|--|---------------------|------------------|
| 客户 | 电池经销商、光伏、EPC | 4S店、道路救援、酒店商场、车队… |
| 卖什么 | 储能电池等 | 移动充电 / 能源方案 |
| 关系 | 制造与品牌背书 | **独立站**，不做成老站的一个分类页 |

**技术路线（已定）：**

- 用代码建站：**Astro**（适合企业站、SEO）
- 样式：**Tailwind CSS**
- 语言：第一版 **只做英文**
- 上线：代码放 **GitHub**，网站挂 **Cloudflare Pages**
- 不选：WordPress / Webflow（第一版，方便以后用 AI 改站）

品牌口号：

> **Power Electric Mobility Beyond the Grid.**  
> （在电网够不到的地方，也能给电动出行供电。）

## 四、网站现在有哪些页面？

浏览器打开后（本地或上线后）大致是这些：

### 1. 首页 `/`

- 品牌首屏（口号 + 按钮）
- 三大优先解决方案入口
- 三个产品层级卡片
- 四个案例卡片
- 联系 CTA（询盘表单还没接真系统）

### 2. 解决方案 Solutions（3 个）

| 页面 | 讲什么 |
|------|--------|
| `/solutions/ev-dealership-charging/` | 4S / 经销商移动充电 |
| `/solutions/ev-roadside-assistance/` | 道路救援补电 |
| `/solutions/ev-charging-without-grid-upgrade/` | 商业场景：无需电网扩容 |

原则：**先讲场景和痛点，再讲设备**（不先砸一堆型号）。

### 3. 产品 Products（3 个层级）

| 型号 | 页面 | 含义 |
|------|------|------|
| **G2V** | `/products/g2v/` | 便携灵活充电（经销商地库等） |
| **M75** | `/products/mobile-battery-station/` | 移动储能充（约 75kWh / 60kW，对应画册 XF-7560 级） |
| **H200** | `/products/commercial-energy-hub/` | 商业能源枢纽（约 200kWh / 120kW，X/F 级） |

还有列表页：`/products/`

### 4. 案例 Cases（4 个）

| 场景 | 页面 |
|------|------|
| 经销商地库 | `/cases/dealership-mobile-charging/` |
| 道路救援 | `/cases/roadside-ev-rescue/` |
| 酒店/商业停车 | `/cases/hotel-charging-without-grid-upgrade/` |
| 工地能源枢纽 | `/cases/construction-mobile-energy-hub/` |

列表页：`/cases/`

### 5. 视觉与品牌

- 整体：**深色 + 青紫波形**（高科技 / Analogue Waves 感觉）
- 商标：用了你提供的 **TAICO 蓝绿条 logo**
- 产品图：按画册/真机参考生成的 **TAICO 品牌效果图**
- 案例图：产品放进真实场景的 **摄影风格图**

**诚实说明（很重要）：**

- 案例里的数字 KPI（比如「转化率 80%」）**没有瞎编**；写的是可运营的定性结果。  
- 以后有真实客户授权数据，再替换成「真名 + 真数据」。  
- 效果图是品牌可视化，不是客户现场原片授权图。

## 五、代码是怎么组织的？（稍微懂一点即可）

网站在 `website/` 里：

```text
website/src/
├── pages/           ← 「网址」对应的页面
│   ├── index.astro              首页
│   ├── products/…               产品
│   ├── solutions/…              方案
│   └── cases/…                  案例
├── components/      ← 页头、页脚、波形背景、CTA 等可复用块
├── layouts/         ← 整页外壳（标题、字体、Header/Footer）
├── data/            ← 文案数据集中放这里（方便改字）
│   ├── solutions.ts
│   ├── products.ts
│   └── cases.ts
└── styles/
    └── global.css   ← 颜色、按钮、玻璃卡片等全局样式
```

**改字优先改 `data/` 里的文件**，往往比在每个页面里翻 HTML 更安全。

静态资源：

```text
website/public/
├── brand/taico-mark.png     TAICO 商标
├── products/*.jpg           产品效果图
└── cases/*.jpg              案例场景图
```

| 步骤 | 状态 |

### Cloudflare 正确设置（抄这个）

| 配置项 | 填什么 |
|--------|--------|
| 仓库 | `miesrock/taico-ev-website` |
| 分支 | `main` |
| **Root directory** | **`website`**（最容易漏！） |
| Build command | `npm run build` |
| Build output | `dist` |
| 环境变量 | 名称 `NODE_VERSION`，值 `22` |

