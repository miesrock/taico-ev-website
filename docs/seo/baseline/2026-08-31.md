## Technical checks recorded

- `npm test`: **56/56 passed**.
- `npm run build`: **37 pages built successfully**.
- All 34 sitemap URLs have a title, meta description, canonical URL, and exactly one H1 in the generated HTML.
- All 34 generated canonical URLs match their sitemap URL exactly.
- `robots.txt` points crawlers to `https://taicoev.com/sitemap-index.xml` and does not block ordinary search crawling.
- Lead capture already carries source component, page path, referrer, UTM fields, and a non-PII `generate_lead` event when analytics consent is granted. This proves instrumentation exists; it does not prove that a lead has occurred or that attribution data is complete in production.

1. Search Console → Performance → Search results → export **Queries** (`query, clicks, impressions, CTR, position`).

3. Search Console → Indexing → Page indexing → record **Indexed** and **Not indexed**.
4. Production lead system → aggregate **total leads**, **organic search leads**, and **lead conversion rate**. Do not paste names, emails, phone numbers, tokens, cookies, or raw lead records into this repository.
